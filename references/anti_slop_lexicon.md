# AI 味诊断词典

> 按需加载。本文件按**五层 + 英文层**组织：词汇层管单个词，句法层管句子形状，衔接层管段与段的接缝，论证层管思维滑坡，结构排版层管整篇的外形。
> 每条格式：**病灶 → 为什么是病 → 怎么改**。所有"怎么改"都必须是可执行的语言动作，不是审美愿望。
> 附录给出 9.14 亿汉字中文语料的实测频率，用来把"少用"变成"每千字不超过几次"。

## §1 词汇层

### 1.1 空转术语表

这些词的共同病理：**它们给现象起了名字，然后假装名字就是解释**。判定法——把这个词从句子里删掉，如果句子的信息量没有减少，这个词就没有承担论证。

| 术语 | 典型滥用 | 它掩盖了什么 | 改写动作 |
|---|---|---|---|
| 机制 | "背后存在复杂的社会机制" | 触发条件、行动者、传递链条 | 写清谁在什么条件下做了什么，结果传给了谁 |
| 逻辑 | "资本的逻辑／下沉的逻辑" | 通常指"道理"而非推理 | 写出推理链或利益链的每一环 |
| 张力 | "两者之间呈现出复杂的张力" | 两端是什么、往哪边拉 | 写出两端各自的内容与拉扯的后果 |
| 范式 | "完成了范式的转换" | 转换的条件与代价 | 写分类标准或因果假设具体变了哪一条 |
| 建构／重构 | "实现了对 X 的重构" | 改写了什么、依据是什么 | 写改动前后的具体差别与证据 |
| 解构 | "传统叙事被解构" | 拆开了什么、露出了什么 | 写被拆的部件与露出的东西 |
| 赋能 | "赋能每一位用户" | 施事与受事 | 写谁给了什么资源，换取了什么 |
| 话语 | "某某话语的生产" | 谁说、在哪说、被谁听见 | 写发话人、场合、听众、后果 |
| 场域 | "在这一文化场域中" | 把空间隐喻当分类 | 指明是制度、关系、资本还是地理 |
| 规训 | 把一切影响称为规训 | 诱导与惩罚的区别 | 写监视、考核、自我审查等具体动作 |
| 异化 | 指一切疏离、变形 | 人与何物分离、如何分离 | 写劳动、产品、自我关系的哪一环断了 |
| 祛魅 | 指一切破除崇拜 | 祛的是哪种魅 | 写哪个具体权威如何被质疑 |
| 现代性 | 用来解释一切 | 具体的制度与感官变化 | 写时间制度、空间经验、身份文书中的哪一项 |
| 他者 | 指一切外人 | 差异在哪个维度、谁定义 | 写差异的具体内容与定义权归属 |
| 主体性 | "主体性被消解" | 谁对什么失去了支配 | 写哪项决定权被谁拿走 |
| 症候 | 指一切迹象 | 可观察的症状与缺失 | 写能被看见的现象与缺席的东西 |
| 底层逻辑 | 指根本原因 | 伪深度，常是同义反复 | 写可被检验的因果链 |
| 抓手／颗粒度／闭环／对齐 | 行政与互联网黑话 | 具体操作、单位、责任人 | 写动作、层级、谁对谁负责 |
| 内卷 | 指一切竞争加剧 | 边际递减与内耗的区别 | 写投入增加、产出未增的具体指标 |
| 生态／链路／心智 | "打造生态／全链路／占领用户心智" | 全是容器名词 | 写具体的交易、环节、记忆对象 |
| 文化资本／惯习／区隔 | 布尔迪厄三件套贴标签 | 转换渠道、身体化过程、等级关系 | 写哪种文化如何换成职位、哪种重复塑造了倾向、谁被排斥 |
| 景观／例外状态／单向度／赤裸生命 | 理论名词当形容词用 | 原概念的限定条件 | 写被观看的场合、哪条法律停摆、哪个质疑渠道被关闭 |

**术语不是禁区，空转才是。** 术语合法使用的唯一条件：**它解释了一个没有它就解释不了的反例**。检验法——删掉含术语的那一整段，论证是否仍然成立？成立，这个术语就是装饰。

### 1.2 万能动词与名物化

汉语原有的及物动词被拆成"弱动词 + 抽象名词"，是中文书面语最常见的注水方式。

| 名物化 | 还原 |
|---|---|
| 进行了详细的研究 | 详查 / 查了三遍 |
| 作出了重大贡献 | 贡献很大 / 捐了两百万 |
| 实现了对……的重构 | 改写了……（并说明改了哪一点） |
| 造成了九十八人死亡 | 死了九十八人 |
| 对……进行分析 | 分析…… |
| 加以解决 / 予以支持 | 解决 / 支持 |
| 开展了深入的讨论 | 讨论了三小时，争的是…… |
| 具有重要的指导意义 | （删；或写出指导了谁的哪个决定） |
| 起到了积极的推动作用 | 推动了什么，推动了多少 |

**规则：看见"进行／作出／实现／加以／予以／给予／开展／完成"＋名词，一律还原为动词。**

### 1.3 空洞评价形容词

深刻、独特、复杂、丰富、强烈、细腻、深情、显著、重要、巨大、动容、震撼、生动、精彩、革命性、前所未有、不可替代、令人印象深刻。

**规则：每个形容词必须在同一句或下一句里跟上一个支点**——一个名词、一个动作、一个坐标、一个数字。否则删。

- "作者笔触细腻" → "母亲的死讯只用一行：'母卒，年四十七。'紧接着写的是米价。"
- "产品体验显著提升" → "首屏加载从 3.2 秒降到 0.9 秒。"
- "影响深远" → "此后三十年，所有省级方志都沿用了这个分类。"

### 1.4 程度与范围副词

全面、深入、进一步、不断、日益、持续、极大地、广泛地、充分、高度、切实、有效。

这些词制造"说了很多"的错觉，实际不增加任何信息。
**规则：删；若确需程度，给基准。** "进一步揭示" → 删；"全面提升" → "在三个指标上提升，第四个没动"；"日益重要" → "2019 年占预算 4%，今年占 19%"。

### 1.5 中文里的翻译腔词

| 翻译腔 | 地道 |
|---|---|
| 基于……的考量 | 因为…… |
| 通过……的方式 | 用…… |
| 在……的情况下 | ……时 |
| 对……而言 | （多数时候可删） |
| 一个……的存在 | （删；直接写它是什么） |
| 做出一个……的决定 | 决定…… |
| 具有……的特点 | 是……的 |
| ……性／……化／……度 的连用 | 拆成动作："可及性不足" → "住得远的人挂不上号" |
| 众所周知 | （删，或给出谁知道、从何时起知道） |
| 正如……所说 | （保留，但必须补出处与原语境） |

## §2 句法层

### 2.1 伪深刻句式（配额制）

它们共同的骗术：**先否定一个弱命题，再肯定一个空命题**，让读者误以为发生了思想转折。

| 句式 | 病理 | 改写规则 |
|---|---|---|
| 不是 A，而是 B | 否定没有对手，肯定没有内容 | 全篇 ≤1 次；否定之后必须立刻给出新证据或新对象 |
| 不仅……更／而且…… | 评价升级，不带新信息 | 升级必须引入一项前文没有的事实 |
| 与其说……不如说…… | 伪二选一 | 先证明两者互斥；证不了就改成比例、条件或时序 |
| 看似……实则…… | 动机揣测冒充洞察 | 换成可观察的行为与后果 |
| 既是……又是…… | 端水 | 写出两者如何冲突、在什么条件下哪一边成立 |
| 从 A 到 B | 伪历史弧线 | 给出两端的具体差异与中间的转折事件 |
| 在……中，……着 | 进行态空转 | 改为具体动作与时间点 |
| 真正的问题不在……而在…… | 已成口头禅 | 同一篇最多一次，且"真正的问题"必须是前文证据逼出来的 |
| 这不仅仅是……的问题 | 拔高 | 删句，直接写它还牵动了什么具体的东西 |

**连续两句使用同一句式即触发警报**，第二次起改为动作句、引文句或比喻句。

### 2.2 端水句式

一方面……另一方面……；既要……也要……；不能简单地说……但也不能……；在 A 与 B 之间寻求平衡；要辩证地看待。

**端水的本质是拒绝解释。** 改写规则：**把"两端"还原成一个变量或一个机制，说明在什么条件下哪一端成立。**

> 一方面反映了传统的生命力，另一方面也暴露了它的困境。
> → 它看起来顽强，是因为仪式成本由村里出；它看起来困难，是因为到场的人越来越把仪式当任务。问题在成本由谁承担。

### 2.3 欧化句式

| 病灶 | 症状 | 改写 |
|---|---|---|
| 长定语前置 | "一批深受中西文化双重影响的知识分子" | 拆成短句后置："读书人受过两套教育，哪一套都不够用" |
| 滥用被动 | "被许多学者所接受""被广泛地传播" | 还原施事："王念孙、段玉裁都引过这条材料" |
| "及／和"硬连异质成分 | "文学及其社会影响和作家的生平" | 拆句 |
| 介词冗赘 | "由于……使得……" | 删"使得" |
| 代词过密 | 每句都补"他／她／它" | 承前省略 |
| 每句补主语 | 中文允许施事隐含在动作里 | 删主语，让动作连续 |
| "当……的时候" | "当我们讨论 X 的时候" | "讨论 X，就会发现……" |
| 从句直译 | "……，这使得……，从而导致……" | 断成三个短句 |

### 2.4 句长与同构

**实测基准**（见附录）：真实中文书面语里，10–39 字的句子占 65.6%，80 字以上的长句不足 3.4%。AI 的典型声纹不是句子太长，而是**句子太匀**。

警报信号：
- 连续三句字数相差不超过 15%；
- 连续三句都是"主语 + 定语 + 谓语 + 宾语"的完整句；
- 连续三句都以相同结构收尾（"……的重要体现""……的集中反映""……的必然结果"）。

**处置：插入一个 5–12 字的短句，让它只承担一个落锤动作。**

### 2.5 标点惯性

- **破折号**：用于突然的补充或语气折转，一篇长文超过 3 次即为惯性。连续两段都出现破折号，删掉其中一个，改成句号或逗号。
- **括号**：不得承担正文信息。读者跳过括号仍应读懂全文；做不到就把括号内容提到正文。
- **冒号**：一段内不超过一次。"原因有三：" 常是列表癖的入口。
- **引号**：给词加引号表示"所谓的"，一段内超过两处就说明作者在躲避判断——要么正面定义，要么换词。
- **感叹号**：严肃写作中几乎不需要。

## §3 段落衔接层

### 3.1 路标词黑名单

首先／其次／再次／最后、此外、另外、与此同时、同时、值得注意的是、需要指出的是、不可否认、众所周知、总而言之、综上所述、由此可见、不难看出、总的来说、换言之、简而言之。

**为什么必须删**：这些词宣称了逻辑关系，却不提供逻辑关系。"首先／其次"只说明有先后，不说明为什么是这个先后；"值得注意的是"只是在求读者注意，不解释为什么值得。它们是衔接失败后贴上去的创可贴。

**唯一的例外**：当内容本身是严格有序的操作步骤时，序号合法。

### 3.2 隐性衔接的五种替代动作

| 动作 | 做法 | 微例 |
|---|---|---|
| 尾—首接力 | 上段结尾的具体物，做下段首句的主语 | "……只能回乡教蒙馆。／蒙馆的学费一年十二石米，不够买他从前一套应试的时文选本。" |
| 张力牵引 | 上段结尾留一个缺口，下段首句回答它 | "……这套估价没有了替代品。／替代品要到十年后才出现。" |
| 具体物位移 | 同一件实物在段落之间移动位置 | 碑→被挪去垫炮架→被立回→被推倒 |
| 指称降格 | 全称 → 简称 → 代词 → 省略，形成信息梯度 | "《明夷待访录》"→"这本书"→"它"→（省略） |
| 对照转折 | 不写"然而"，让两个事实的反差自己构成转折 | "小册子确实便宜。纽伦堡的档案里，同一印本在相邻两个教区的查禁程度相差六倍。" |

详细技法与更多例子见 `craft_rhythm_and_flow.md` §1。

### 3.3 机械化主题句

每段都以一句概括性陈述开头、后面三句举例说明——这是中学作文训练留下的、也是语言模型最爱复制的段落形状。

**处置：让至少三分之一的段落从一个具体物、一个动作或一句引文开始，把概括放到段尾或根本不写。**

## §4 论证层

| 编号 | 滑坡 | 识别信号 | 纠正动作 |
|---|---|---|---|
| L1 | 道德评价代替结构解释 | 贪婪／冷漠／愚昧直接推出制度结论 | 换成人事、账目、激励、信息四类变量 |
| L2 | 单一因果 | "正是……直接导致了……" | 补中间环节、反例、控制变量；把"导致"降级为"放大" |
| L3 | 相关当因果 | 时间先后 + 共变 | 找机制，排除第三变量 |
| L4 | 结论超出证据 | 个案推出全称判断 | 降级结论，写明适用范围 |
| L5 | 循环论证 | 结论换词复述前提 | 找一个独立于前提的证据 |
| L6 | 价值先行 | 开头就定好坏 | 先描述，再判断 |
| L7 | 伪问题 | 无张力、不可证伪 | 用反例重造问题 |
| L8 | 稻草人 | 对手观点被简化到可笑 | 先写出对方的最强版本再反驳 |
| L9 | 权威代替论证 | "某某大师指出" | 复述其最强论证，再推进 |
| L10 | 概念空转 | 删掉理论段论证仍成立 | 理论必须回答"没它哪一步推不动" |
| L11 | 材料与理论两张皮 | 材料段与理论段交替出现 | 让概念从材料的动作里长出来 |
| L12 | 报菜名式综述 | A 认为、B 认为、C 认为 | 按争论焦点／方法分歧／盲区重组 |
| L13 | 均质化主体 | "古人""女性""年轻人"无差异 | 补阶层、地域、年龄、制度位置 |
| L14 | 现代中心主义 | 以今天的标准判古人 | 先解释它当时如何自洽，再评价 |
| L15 | 术语时代错置 | 用现代范畴描述古代 | 区分分析概念与当时的自称 |
| L16 | 虚假精确 | "提升了 37.2%" 无基准无口径 | 给基准、样本量、统计口径、时间窗 |
| L17 | 以定义代替论证 | 先定义，然后结论从定义里掉出来 | 定义后置；用材料检验定义 |
| L18 | 幸存者偏差 | 只分析成功案例 | 找到同条件下失败的那一批 |
| L19 | 以流行度代替证据 | "越来越多的人认为" | 给出谁、多少、怎么统计 |
| L20 | 想象越过证据 | "必然""一定""可以想见" | 区分实证与推测，并标明 |
| L21 | 案例代表性未经辩护 | "我研究的这个县" | 说明典型性、边界与可推广范围 |
| L22 | 理论当真理 | 把理论当判决书 | 当工具用，写出适用范围与盲区 |

## §5 结构与排版层

**结构癖**：把任何内容都拆成"小标题 + 三个要点"。病理——要点之间的关系（因果、轻重、先后）被抹掉了，而这正是作者该负责的部分。处置：除非内容本身就是并列清单，否则改写为连续段落，并在改写时显式交代要点之间的关系。

**对称强迫症**：每一节都是三点，每一点都是两句。真实的思考不对称，重要的部分应该更长。

**加粗滥用**：加粗用于让读者在扫读时能定位，不用于强调重要性。一屏超过三处加粗，等于没有加粗。

**emoji 与装饰符号**：严肃写作中一律不用。

**元话语**：本文将探讨／接下来我们来看／在深入分析之前／让我们首先了解。处置：全删。读者不需要导游，需要内容。

**标题套路**：深度解析／全面剖析／一文读懂／你需要知道的 N 件事／那些……的事。处置：标题应当给出文章的判断或具体对象。

**收尾套路**：综上所述 + 复述 + 升华 + 倡议。处置：结尾只允许四选一——落锤的判断、未解的问题、一个具体画面、一句限定（这个结论在哪里失效）。

## §6 英文写作专属层

> 本层为补盲：原始语料全部为中文，但 AI 腔在英文里有独立且更强的声纹。以下为本 Skill 基于前沿模型输出特征补充。

### 6.1 词汇黑名单

delve, tapestry, testament, realm, landscape, navigate, underscore, pivotal, crucial, robust, leverage, harness, foster, meticulous, intricate, multifaceted, nuanced, seamless, holistic, paradigm, synergy, game-changer, unlock, empower, elevate, curate, resonate, embark, myriad, plethora, vibrant, bustling, ever-evolving, fast-paced.

### 6.2 句式黑名单

- `In today's [adjective] world/landscape, ...` —— 删整句。
- `It's worth noting that ...` / `It's important to remember that ...` —— 删前缀，直接写内容。
- `This isn't just X — it's Y.` —— 英文版"不是 A 而是 B"，全篇 ≤1 次。
- `Not only ... but also ...` —— 改成两个句子。
- **句尾分词总结从句**：`..., highlighting the importance of ...` / `..., underscoring a broader shift toward ...` —— **这是最可靠的 LLM 指纹**。处置：删掉整个分词短语；如果信息重要，另起一句写成主谓结构。
- **三连排比**：`fast, reliable, and scalable` —— 英文 AI 偏爱三项式。改成两项或四项，或给每项一个不同的句法形状。
- `Here's the thing.` / `But here's the catch.` / `The result?` —— 伪口语节拍器。
- `From X to Y, ...` 开头 —— 伪覆盖面。
- 每段恰好三句、每节恰好三段 —— 打破它。

### 6.3 标点

- **Em dash**：LLM 的高频惯性。一篇 1000 词的文章超过 2 个即删到 2 个以内。
- **Semicolon**：英文严肃散文里合法，但连续两段出现即为惯性。
- **Rhetorical question + answer**：`Why does this matter? Because ...` —— 一篇最多一次。

### 6.4 英文的正向动作

写具体的名词（`a 1987 memo`，不是 `historical documentation`）；用主动语态和强动词（`cut`, `missed`, `refused`, `kept`，不是 `was implemented`, `was leveraged`）；让句长在 4 字和 40 字之间起伏；允许一个段落只有一句话。

### C. 可数的自检阈值

1. **"进行／不是／而是／随着／全面／进一步／不断"合计 > 8 次/千字** → 压缩。
2. **"不是 A，而是 B"全篇 > 1 次** → 改写多余的。
3. **空洞形容词无支点率 > 20%** → 逐个补支点或删。
4. **连续三句长度差 < 15%** → 插入短句。
5. **列表与小标题占全文篇幅 > 30%（且内容不是清单）** → 改写为成文段落。
6. **破折号 > 3 次/千字，或括注承担了正文信息** → 删改。
7. **段首路标词 > 0 次** → 全删，改用 §3.2 的五种衔接动作。
8. **形容词总数 > 实词的 8%** → 删。

### D. 本语料的一项反面发现

该语料蒸馏出的 8,000 条"高分"现代汉语句子，绝大多数是百科式定义开头：「《X》是 A 于 Y 年出版的……」「X 位于……，是……之一」。它们信息密度很高、判断力极低，是**"信息满而判断空"的标准样本**。

**结论：信息密度不等于论证。** 一句话塞进地名、年代、比例、旧称、英文括注，读者仍然得不到"所以呢"。凡写出这种句子，追问一句：**这条信息改变了读者的什么判断？** 答不出就删。
